# MSME Lending Decision System - Frontend

Frontend application for MSME Lending Decision System built using React, Vite, Axios, and Tailwind CSS.

## Live Demo

Netlify Deployment:
https://vitto-front.netlify.app

---

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios
- Lucide React

---

## Features

- Responsive lending application form
- Real-time API integration
- Credit decision result card
- Error handling and validations
- Clean UI design
